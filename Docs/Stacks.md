# Stack Tecnológico

#### IAs de apoyo
| IA | Utilización |
| :--- | ---: |
| Gemini | Tareas simples y búsqueda de información. |
| ChatGPT | Corrección de documentos Markdown y diagramas. |
| Claude | Lógica, diagramado y aprendizaje sobre tecnologías usadas. |
| Antigravity | Pair programming, refactorización y testeo. |

#### Lenguajes de programación
| Lenguaje | Versión | Utilización |
| :--- | :--- | ---: |
| **Java** | **17 LTS** | Estructura, lógica de negocio y componentes de la aplicación. Se utiliza una versión Long-Term Support (LTS) para garantizar estabilidad y compatibilidad. |

#### Gestor de dependencias y construcción
| Herramienta | Versión | Utilización |
| :--- | :--- | ---: |
| **Apache Maven** | **3.8+** | Gestión de dependencias, configuración del compilador y automatización de empaquetado del proyecto. |

#### Librerías y APIs del JDK
| Librería / Módulo | Origen | Utilización |
| :--- | :--- | ---: |
| **JUnit 5 (Jupiter)** | Dependencia Maven (`5.10.2`) | Pruebas unitarias automatizadas para validar la lógica del repositorio, búsquedas y lectura/escritura de archivos TSV. |
| **java.nio.file** | Estándar del JDK 17 | Manejo seguro y eficiente de lectura y escritura de archivos en disco sin dependencias externas. |
| **java.time** | Estándar del JDK 17 | Manejo estandarizado de fechas bajo norma ISO-8601 (`LocalDate`). |

#### Interfaz Gráfica (UI)
| Tecnología | Toolkit | Utilización |
| :--- | :--- | ---: |
| **Swing** | Estándar del JDK (Desktop) | Ventana principal de la aplicación, formularios de carga rápida de palabras y tabla de visualización con soporte de filtros. |

#### Control de versiones
| Herramienta | Utilización |
| :--- | ---: |
| **Git & GitHub** | Control de versiones local y remoto, con archivo `.gitignore` estandarizado para excluir artefactos generados (`target/`, `.class`) y configuraciones de IDE. |
