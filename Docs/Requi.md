# Requisitos funcionales:

* **RNF-01 — Guardado de palabras:** Los usuarios tienen que poder guardar las palabras y que estas esten asociadas con: definiciones, fuente y fecha. Todo esto dentro del mismo dispositivos donde corre la aplicación.
* **RNF-02 — Separar los conjuntos de palabras por idiomas:** Si el usuario tiene palabras en inglés y español guardadas, tienen que estar separadas. No obstante, que no estén en distintas clases pues me gustaría agregar otros idiomas si se presenta el caso.
* **RNF-03 — Edicción de datos:** El sistem debe permitir editar cualquiera de los datos asociados a las palabras. Sin importar el tipo de dato que sea.
* **RNF-04 —: Busqueda de palabras:** Ya sea por palabras asociadas en la definición o que busque la palabra en si, este tiene que poder acceder a ellas.
* **RNF-05 — Lectura:** El usuario tiene que ser capaz de leer las palabras y datos asociados ya guardados.
